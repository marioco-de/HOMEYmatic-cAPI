# Assets

Dieser Ordner enthält die App-Icons und Bilder.

## Erforderliche Dateien

- `icon.svg` - Haupt-App-Icon im SVG-Format (Pflicht für Homey)
- `images/large.png` - Großes App-Icon (500x500px)
- `images/small.png` - Kleines App-Icon (250x250px)

## Format-Anforderungen

**SVG-Icon (icon.svg):**
- Muss im SVG-Format sein
- Wird von Homey CLI validiert
- Sollte 500x500 Viewbox haben
- Wird für verschiedene Zwecke in Homey verwendet

**PNG-Icons (images/):**
- Im PNG-Format
- Transparenter Hintergrund empfohlen
- Das Homematic IP Logo oder ein passendes Icon

## Design

Die Icons verwenden das Homematic IP Farbschema:
- Primär: #0066CC (Blau)
- Weiß für Kontraste
- Haus-Symbol als Hauptmotiv
