📚 Erste Schritte: HCU Developer Mode aktivieren ▼
🎯 Was Sie benötigen:
• Home Control Unit (HCU) im lokalen Netzwerk
• SGTIN Ihrer HCU (24-stellige Seriennummer)
• Zugriff auf das HCU Web-Interface
• Ca. 5-10 Minuten Zeit
🔑 SGTIN finden:
Die SGTIN finden Sie:
• Auf der Rückseite der HCU (Aufkleber) - 24 Zeichen
• In der Homematic IP App: Einstellungen → Access Point → Details
• Beispiel volle SGTIN: 1234A123B12312C3123412D3
• Für die Suche: Nur die letzten 4 Zeichen → 12D3

Schritt 1: HCU Web-Interface öffnen

Öffnen Sie in Ihrem Browser das HCU-Interface:

https://hcu1-XXXX.local:6969

Wobei XXXX die letzten 4 Zeichen Ihrer SGTIN sind

Beispiel: Bei SGTIN 1234A123B12312C3123412D3 → https://hcu1-12D3.local:6969

Oder verwenden Sie die IP-Adresse: https://192.168.X.X:6969

⚠️ Zertifikatswarnung: Ihr Browser wird eine Sicherheitswarnung anzeigen (selbstsigniertes Zertifikat). Klicken Sie auf "Erweitert" und dann "Trotzdem fortfahren" oder "Ausnahme hinzufügen".

Schritt 2: Developer Mode aktivieren

  1. Melden Sie sich im HCU Web-Interface an
  2. Navigieren Sie zu Einstellungen (⚙️ Symbol)
  3. Wählen Sie "Entwickler & Tests" oder "Developer Mode"
  4. Aktivieren Sie den Developer Mode (Schalter auf ON)
  5. Bestätigen Sie die Warnung
✅ Geschafft! Der Developer Mode ist jetzt aktiviert. Die HCU erlaubt nun Connect API Verbindungen.

Schritt 3: Activation Key generieren

  1. Im Developer Mode Bereich, klicken Sie auf "Activation Key generieren"
  2. Sie erhalten einen 6-stelligen Code (z.B. A1B2C3)
  3. Dieser Code ist 30 Minuten gültig
  4. Verwenden Sie ihn unten im Token-Generator
💡 Tipp: Lassen Sie das HCU Web-Interface geöffnet, während Sie unten die Konfiguration durchführen.

⚙️ Konfiguration

Hostname (mit letzten 4 Zeichen der SGTIN) oder IP-Adresse Ihrer Home Control Unit (ohne http:// oder Port)
Die letzten 4 Zeichen der SGTIN finden Sie auf der Rückseite Ihrer HCU (z.B. bei 1234A123B12312C3123412D3 → 12D3)
Der Authorization Token von der Connect API (64 Zeichen Hex-String)
Eindeutige Plugin-ID (Standard: de.maricode.homeymatic.capi)

📖 Manuelle Token-Generierung (empfohlen) ▼

Token manuell generieren mit Postman, curl oder ähnlichen Tools:

📋 Schritt-für-Schritt Anleitung:

1. Activation Key generieren

Öffnen Sie das HCU Web Interface (z.B. https://hcu1-1234.local:6969) → Einstellungen → Entwicklermodus → Activation Key generieren

Sie erhalten einen 6-stelligen Code wie ABCDEF

2. Token anfordern

POST https://hcu1-XXXX.local:6969/hmip/auth/requestConnectApiAuthToken

Header:
  Content-Type: application/json
  VERSION: 12

Body:
{
  "activationKey": "ABCDEF",
  "pluginId": "de.maricode.homeymatic.capi",
  "friendlyName": {
    "de": "Homey Integration",
    "en": "Homey Integration"
  }
}

Response: Sie erhalten einen authToken zurück

3. Token bestätigen

POST https://hcu1-XXXX.local:6969/hmip/auth/confirmConnectApiAuthToken

Header:
  Content-Type: application/json
  VERSION: 12

Body:
{
  "activationKey": "ABCDEF",
  "authToken": "9889E835DC50A1D32A200CA17CC26906..."
}

Response: Token ist jetzt aktiviert und kann verwendet werden!

4. Token in Homey eintragen

Kopieren Sie den authToken (64 Zeichen) und tragen Sie ihn oben im Feld "Auth Token" ein.
